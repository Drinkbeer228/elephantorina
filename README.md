# Elephantorina

Экзаменационный зал Elephant Research Station: тесты по книгам библиотеки «Слонологии».
Теория живёт в книгах (Research Station → библиотека), здесь — только проверка: вопросы, клинические случаи и термины.

## Как устроено

- **Тема = книга.** Каждый тест привязан к id книги из каталога библиотеки (`anatomy/…`, `veterinary/…`).
- **Вход из библиотеки:** `…/elephantorina/?book=<id книги>` открывает тест этой книги. Старые ссылки
  `?course=&lesson=` переводятся на книгу через `src/bank/lessonLinks.ts`.
- **Режимы:** тренировка (разбор после каждого ответа), зачёт (разбор в конце), термины (карточки),
  смешанный тест по всем книгам, работа над ошибками.
- **Попытка** — до 12 вопросов; если в книге меньше, берутся все. В приоритете вопросы с ошибками, затем ещё не пройденные.
- **Отметка «Зачёт сдан» с процентом** ставится только в режиме зачёта, от 80%. Очков, званий и звуков нет.
- **Прогресс** — в `localStorage` этого устройства (`elephantorina.progress.v2`), без аккаунтов и серверов.
  Перенос между устройствами — «Сохранить в файл» / «Загрузить из файла» внизу главной (`.json`, результаты объединяются).
- **Без привязки к книге** — вопросы, которым ещё не нашлась книга: в тестах по книгам их нет, в общем смешанном тесте есть.
- **Список на наполнение** — страница «Список» и файл `docs/knowledge-base.md`.

## Где что лежит

| Путь | Что |
|---|---|
| `src/bank/topics/*.ts` | База знаний: один файл — одна книга. Формат — `src/bank/topics/README.md` |
| `src/bank/lessonLinks.ts` | Какой урок старого курса к какой книге относится |
| `src/bank/legacy/` | Старый курс: из него берутся вопросы, случаи и карточки |
| `src/bank/books.json` | Снимок каталога библиотеки |
| `src/test/` | Логика теста и прогресса (без React) |
| `src/ui/` | Экраны |

## Команды

```bash
npm run dev            # разработка
npm test               # логика + проверка банка (книги существуют, id уникальны, ответы корректны)
npm run coverage       # обновить docs/knowledge-base.md
npm run sync:catalog   # обновить снимок каталога (по умолчанию из ../research-station)
npm run build
```

`VITE_STATION_URL` — адрес Research Station (по умолчанию `https://drinkbeer228.github.io/research-station/`).
