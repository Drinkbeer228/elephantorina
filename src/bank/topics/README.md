# База знаний: вопросы по книгам

Один файл — одна книга библиотеки. Имя файла любое, удобно повторять id книги: `anatomy--cardiovascular-system-and-hemodynamics.ts`.
Файл подхватывается сам, регистрировать его нигде не нужно. Какие книги ждут вопросов — `docs/knowledge-base.md`
(обновить: `npm run coverage`) или страница «Список» в приложении.

```ts
import type { TopicFile } from '../types';

export default {
  // id книги — как в каталоге библиотеки (и в адресе книги на станции: #/library/<id>)
  book: 'anatomy/cardiovascular-system-and-hemodynamics',

  questions: [
    {
      kind: 'choice',
      id: 'cardio-01',                 // уникальный и постоянный: по нему хранится прогресс
      prompt: 'Вопрос?',
      options: ['Вариант А', 'Вариант Б', 'Вариант В', 'Вариант Г'],
      answer: 1,                       // индекс правильного варианта, с нуля
      explanation: 'Почему правильный — правильный.',
      optionNotes: [                   // необязательно: разбор каждого варианта
        'Почему не А', undefined, 'Почему не В', 'Почему не Г',
      ],
      section: 'Название раздела книги', // необязательно: где искать ответ
    },
    {
      kind: 'case',                    // случай: ситуация и варианты действий
      id: 'cardio-case-01',
      title: 'Короткое название',
      subject: { name: 'Азиатская слониха', age: 25, role: 'Зоопарк' }, // необязательно
      situation: 'Что произошло. Ваши действия?',
      options: [
        { text: 'Действие 1', correct: true, feedback: 'Почему это верно.' },
        { text: 'Действие 2', correct: false, feedback: 'Почему нет.' },
      ],
    },
  ],

  // Термины: идут в карточки и автоматически превращаются в вопросы «Что означает…?»
  terms: [
    { id: 'cardio-t-01', term: 'Термин', definition: 'Определение.' },
  ],
} satisfies TopicFile;
```

В тексте работают `**жирный**`, `*курсив*`, `$формулы$` (`$Elephas\ maximus$` — латинское название курсивом),
абзацы — через пустую строку.

Перед коммитом: `npm test` проверяет, что книга есть в каталоге, id не повторяются и правильный ответ существует.
Если каталог библиотеки обновился: `npm run sync:catalog [путь-или-URL catalog.json]`.
